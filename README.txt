=============================================================================
              TOTVS WEBAGENT MANAGER (.EXE) - GUIA DE USO
=============================================================================

Aplicacion grafica nativa para administrar y cambiar versiones de TOTVS WebAgent 
entre multiples clientes de Protheus de forma instantanea y visual.

-----------------------------------------------------------------------------
1. COMO USAR O INSTALAR
-----------------------------------------------------------------------------
- Opcion A (Directa): Ejecuta directamente "WebAgentManager.exe".
- Opcion B (Crear acceso directo): Ejecuta "Instalar.bat" para que cree el 
  icono oficial en el Escritorio (compatible con OneDrive y no requiere Admin).

-----------------------------------------------------------------------------
2. CARACTERISTICAS PRINCIPALES
-----------------------------------------------------------------------------
- [ + Nuevo Cliente ]: Abre un formulario donde ingresas el Nombre del cliente, 
  su IP/URL y seleccionas del desplegable que version de WebAgent debe usar.
- [ Editar ]: Permite cambiar el nombre, IP o actualizar la version del WebAgent 
  asignada a ese cliente.
- [ Activar ]: Con 1 solo clic deja lista esa version en Windows para que 
  entres desde tu navegador de inmediato.
- [ 🔍 Escanear Equipo ]: Busca automaticamente en tu computadora (en Programs, 
  Descargas, etc.) cualquier instalador o version existente de WebAgent y la 
  agrega a tu lista desplegable.
- [ 📥 Importar Instalador ]: Permite seleccionar cualquier instalador oficial 
  de WebAgent (.exe) y lo extrae automaticamente para tenerlo disponible.
- [ 🧹 Limpiar Puertos Libres ]: Libera procesos en espera sin desconectar 
  sesiones activas de Protheus.
- [ ⚡ Cerrar Todo ]: Fuerza el cierre total de todos los procesos en memoria.
=============================================================================
